# execdlib
## （移行について）EX拡張フォントキットの使用をおすすめします。
EX拡張文字表示ライブラリは、Cソースにフォントデータを埋め込みます。アプリに直接データを埋め込むため、ユーザーが追加で操作をする必要がありません。しかし、Cソースのサイズが大きくなり他の操作でメモリが足りなくなったり、一定の文字数（およそ800文字）を超えるとコンパイルに失敗したりします。対してEX拡張フォントキットはファイル（EXF）からフォントデータを読み込みます。ユーザーがフォントデータを転送する必要があるとはいえ、ストレージが許す限りメモリを気にすることなく扱うことができますし、便利な機能が多く追加されていますので、[EX拡張フォントキット](https://github.com/kwmsnode/exefkit)をご利用ください。
## 概要
EX-word非公式開発環境でワイド文字を含む文字列を表示できるようにするCライブラリ。
